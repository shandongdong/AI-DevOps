# References — 外部参考资料

> 本目录存放**外部资料的内化副本或指引**——把对开发/Agent 有用的第三方文档、llms.txt、技术规范摘要等收录进来，让 Agent 在仓库内就能读到，不必外求。呼应 OpenAI 铁律 2「代码仓库即记录系统」——Agent 运行时访问不到的东西对它等于不存在。

## 用途

收录什么：

- **llms.txt / llms-full.txt**：第三方库/框架写给 LLM 的官方说明（如 nixpacks-llms.txt、uv-llms.txt），让 Agent 知道怎么用这个工具。
- **技术规范摘要**：某项标准/协议的精简版（如设计系统参考、部署规范摘要），原文太长或难访问时，内化一份。
- **外部决策记录**：影响本项目的外部讨论结论、RFC 摘要。

不收录什么：

- 项目自身的设计文档 → 放 `design-docs/`
- 功能模块全貌 → 放 `product-specs/`
- SDD 流程产物 → 放 `specs/`

## 命名约定

```
docs/references/
└── <来源>-<主题>.md        # 如 nixpacks-llms.txt / openai-harness-summary.md
```

用「来源-主题」命名，一眼看出谁出的、讲什么。

## 维护规则

- 收录时注明原文出处（URL + 访问日期），便于追溯。
- 外部资料更新时，视重要性决定是否同步内化副本。
- 本目录是**只读参考资料**，不改原文含义，必要时加项目特定的注解段。
