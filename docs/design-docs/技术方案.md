## 二、功能列表

项目由 **若依基础功能** + **自有业务模块（ai-devops）** 两部分组成：

| 分类 | 模块 | 状态 |
|------|------|------|
| 系统管理 | 用户/角色/菜单/部门/岗位/字典/参数/通知公告 | ✅ 若依自带 |
| 系统监控 | 操作日志/登录日志/在线用户/服务监控/缓存监控/数据源监控 | ✅ 若依自带 |
| 定时任务 | Quartz 任务调度 | ✅ 若依自带 |
| 代码生成 | 基于表的单表/树表/主子表 CRUD 生成 | ✅ 若依自带 |
| 开发工具 | OpenAPI 接口文档、表单构建 | ✅ 若依自带 |
| 自有业务 | ai-devops 模块（健康检查接口，业务待规划） | 🚧 建设中 |

> ai-devops 当前仅落地一个健康检查接口 `GET /aidevops/health`（带 `@Anonymous` 白名单，可直接浏览器访问），用于验证模块创建成功。

## 三、开发环境配置

### 3.1 开发环境准备

| 工具 | 版本要求 | 说明 |
|------|----------|------|
| JDK | 17+ | 编译运行后端 |
| Maven | 3.8+ | 后端依赖管理与构建 |
| Node.js | 18+ | 前端运行（corepack 启用 yarn） |
| MySQL | 8.0 | 数据库（字符集 utf8mb4） |
| Redis | 6+ | 缓存与 token |

### 3.2 服务端工程配置

关键配置文件（均位于 `ruoyi-admin/src/main/resources/`）：

- `application.yml`：服务端口（8080）、文件上传路径（`./ruoyi/uploadPath`）、Redis 连接、验证码开关等；默认激活 `dev,druid-dev`
- `application-druid-{dev,test,prod}.yml`：三环境数据源（Druid 主从、连接池、监控，凭据 `${ENV_VAR:默认值}` 环境变量化）
- `logback.xml`：日志输出路径（`./ruoyi/logs`）与格式

> ⚠️ 数据源、Redis 等连接信息含内网地址与密码，本地配置勿提交真实凭据（详见 [项目开发规范](项目开发规范.md) 的安全规范）。

### 3.3 前端工程配置

前端位于 `ruoyi-ui-vue3/`，使用 `vite.config.ts` 配置 devServer 代理（默认代理后端 8080）。

## 四、部署方法

### 4.1 后端部署

```bash
# 在项目根目录打包
mvn clean package -DskipTests

# 启动（生成的可执行 jar 在 ruoyi-admin/target/ruoyi-admin.jar）
java -jar ruoyi-admin/target/ruoyi-admin.jar
```

启动成功标志：日志出现 `Started RuoYiApplication` 与若依启动 banner，端口 `http-nio-8080`。

### 4.2 前端部署

```bash
cd ruoyi-ui-vue3
yarn --registry=https://registry.npmmirror.com   # 安装依赖
yarn dev                                           # 开发（端口 80，代理后端 8080）
yarn build                                         # 生产构建，产物在 dist/
```

### 4.3 联调

后端默认 8080，前端 devServer 代理已指向 8080，本地同时启动后端 + `yarn dev` 即可联调，访问 `http://localhost:80`。

## 五、关键配置文件说明

| 文件 | 路径 | 作用 |
|------|------|------|
| 根 pom | `pom.xml` | 聚合 7 个模块、统一版本管理 |
| 启动类 | `ruoyi-admin/.../RuoYiApplication.java` | `@SpringBootApplication(exclude=DataSourceAutoConfiguration.class)` |
| 主配置 | `ruoyi-admin/.../application.yml` | 端口 8080 / 上传路径 / token / MyBatis（不含 Redis/Flyway） |
| 数据源 | `ruoyi-admin/.../application-druid-{dev,test,prod}.yml` | 三环境 Druid 主库连接（凭据环境变量化） |
| 日志 | `ruoyi-admin/.../logback.xml` | 日志路径与格式 |
| 数据库迁移 | `ai-devops/src/main/resources/db/migration/V1__ruoyi_base_tables.sql`、`V2__quartz_tables.sql` | 基础表与定时任务表（Flyway 管理，V3+ 业务表） |
