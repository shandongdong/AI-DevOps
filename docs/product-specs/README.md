# Product Specs — 功能模块完整静态文档

> 本目录存放**功能模块的完整静态文档**——从需求、技术方案到开发文档，一篇文章看懂某个模块的全貌。

## 定位：与 specs/ 的区分

| | `specs/NNN-slug/` | `docs/product-specs/`（本目录）|
|---|---|---|
| 性质 | **动态**迭代产物（SDD 流程中持续更新）| **静态**固化档案（完成后归档）|
| 内容 | spec.md / plan.md / tasks.md（过程产物）| 模块全貌文档（需求+方案+文档合一）|
| 生命周期 | 随时间归档或删除 | 长期保留，看模块全貌的入口 |
| 读者 | SDD 流程参与者（AI + 开发者）| 想了解某功能全貌的人 |

**两者独立维护，不自动转化**。`specs/` 是 SDD 流程的工作产物；`product-specs/` 是完成后的固化档案。完成一个功能后，如需留全貌文档，手写一份放本目录，不依赖 specs 自动生成。

## 命名约定

```
docs/product-specs/
└── <功能名>.md        # 如 health-check.md / calculator.md
```

用功能语义名（非 NNN 编号），便于直接按功能名查找。

## 维护规则

- 功能完成后，如需留全貌文档，手写一份放本目录。
- 内容涵盖：需求背景、技术方案、接口契约、数据模型、开发文档要点。
- 与 `specs/` 的 SDD 产物保持事实一致（`/speckit-scan` 可查漂移）。
- 本目录文档是**静态档案**，功能演进时同步更新，但不记录过程状态。
