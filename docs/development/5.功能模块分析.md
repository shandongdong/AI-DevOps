# 功能模块分析

> 项目共 7 个 Maven 模块。`ruoyi-admin` 是启动模块，Controller 集中在 admin 的 `web/controller` 下；业务实现分布在 `ruoyi-system`（系统业务）、`ruoyi-quartz`（定时）、`ruoyi-generator`（代码生成），自有业务在 `ai-devops`。

## 一、系统管理模块（ruoyi-system + admin Controller）

| 功能 | Controller | Service 接口 | 说明 |
|------|------|------|------|
| 用户管理 | SysUserController | ISysUserService | 用户增删改查、重置密码、导入导出、角色分配 |
| 角色管理 | SysRoleController | ISysRoleService | 角色、数据权限（部门范围）、用户授权 |
| 菜单管理 | SysMenuController | ISysMenuService | 菜单/权限树、路由生成（前端动态路由来源） |
| 部门管理 | SysDeptController | ISysDeptService | 部门树、数据权限范围 |
| 岗位管理 | SysPostController | ISysPostService | 岗位 CRUD |
| 字典管理 | SysDictTypeController / SysDictDataController | ISysDictTypeService / ISysDictDataService | 字典类型与字典数据 |
| 参数管理 | SysConfigController | ISysConfigService | 系统参数（如验证码开关） |
| 通知公告 | SysNoticeController | ISysNoticeService / ISysNoticeReadService | 公告与已读记录 |
| 个人中心 | SysProfileController | — | 个人资料、修改密码 |
| 登录/注册 | SysLoginController / SysRegisterController / CaptchaController | — | 登录鉴权、注册、验证码 |
| 首页 | SysIndexController | — | 首页提示语、锁屏解锁 |

## 二、系统监控模块（admin Controller）

| 功能 | Controller | 说明 |
|------|------|------|
| 操作日志 | SysOperlogController | 操作审计记录查询 |
| 登录日志 | SysLogininforController | 登录审计、登出、解封 |
| 在线用户 | SysUserOnlineController | 在线用户列表、强退 |
| 服务监控 | ServerController | CPU/内存/磁盘/JVM（oshi） |
| 缓存监控 | CacheController | Redis 缓存信息、键值查询、删除 |
| 数据源监控 | （Druid 内置） | `/druid/**` SQL 监控（已加白名单） |

## 三、定时任务模块（ruoyi-quartz）

包结构：`controller / service / mapper / domain / task / util / config`

| 功能 | 说明 |
|------|------|
| 任务管理 | 新增/修改/删除/暂停/恢复/立即执行 Cron 任务 |
| 任务日志 | 任务执行记录 |
| 调度引擎 | Quartz，支持 Cron 与 Simple 触发器 |

## 四、代码生成模块（ruoyi-generator）

包结构：`controller / service / mapper / domain / config / util`

| 功能 | 说明 |
|------|------|
| 表查询 | 读取数据库表结构，生成到 `gen_table` / `gen_table_column` |
| 代码生成 | 基于表生成 Controller/Service/Mapper/Domain/XML/SQL/前端 Vue，Velocity 模板 |
| 支持形式 | 单表、树表、主子表 |

## 五、开发工具模块

| 功能 | 位置 | 说明 |
|------|------|------|
| 接口文档 | springdoc + Swagger UI | `/swagger-ui/**`、`/v3/api-docs/**`（已加白名单） |
| 表单构建 | admin web/controller/tool | 拖拽生成表单 |
| 测试接口 | TestController | 接口示例 |

## 六、ai-devops 自有业务模块

包：`com.ruoyi.aidevops.*`（按功能域分子包，上游零触碰）。分层 `controller / service / mapper / domain`，业务表走 Flyway 迁移，菜单/权限走 `sys_menu` 数据驱动。

| 功能 | 接口 | 说明 | 状态 |
|------|------|------|------|
| 健康检查 | `GET /aidevops/health` | 返回模块状态，带 `@Anonymous` 白名单，浏览器可直访 | ✅ 已落地（SDD 规范见 [`specs/001-health-check/`](../../specs/001-health-check/spec.md)） |
| 计算器 | `POST /aidevops/calc/compute` | 四则运算（`@RequestBody` 传 operator/first/second），权限 `aidevops:calc:compute`，合法运算落库历史 | ✅ 已落地（SDD 规范见 [`specs/002-calculator/`](../../specs/002-calculator/spec.md)） |
| 计算历史 | `GET /aidevops/calc/list` | 分页查询本人历史，按运算符/时间过滤，数据按用户隔离 | ✅ 已落地 |
| 计算历史删除 | `DELETE /aidevops/calc/{calcIds}` | 软删除（`del_flag` 置 '2'），权限 `aidevops:calc:remove`，支持批量 | ✅ 已落地 |

> 计算器功能是 SDD 端到端交付的第一个业务验证（spec→plan→tasks→implement 全流程，含数据库/Flyway/单元测试/前端两页）。后续业务功能将在此模块内按功能域子包扩展，详见 [8.项目开发规范](8.项目开发规范.md)。

## 七、通用工具与框架核心

### 7.1 ruoyi-common（通用工具）

| 子包 | 内容 |
|------|------|
| annotation | `@Anonymous`、`@DataScope`、`@DataSource`、`@Excel`、`@Log`、`@RateLimiter`、`@RepeatSubmit`、`@Sensitive` |
| core | `AjaxResult`、`BaseController`、`BaseEntity`、分页、Redis、文本、domain 实体基类 |
| utils | `SecurityUtils`、`StringUtils`、`DateUtils`、`ServletUtils`、`PageUtils`、`DictUtils`、`Arith`(精度)、poi/http/html/ip/file 等 |
| config | 全局配置、序列化器 |
| enums | 枚举常量 |
| exception | 自定义异常 |
| filter / xss | 请求过滤、XSS 清洗 |

### 7.2 ruoyi-framework（框架核心）

| 子包 | 内容 |
|------|------|
| config | `SecurityConfig`、`DruidConfig`、`MyBatisConfig`、`XssFilter`、`PermitAllUrlProperties`、`ApplicationConfig` 等 |
| datasource | 多数据源（主从） |
| security | 认证过滤器、登录处理、token 校验、SecurityContext |
| aspectj | `@DataScope`、`@Log`、`@DataSource` 切面实现 |
| web | `server`、`service`、`domain`、`exception` 等 Web 层支持 |
| interceptor | 拦截器（防重复提交等） |
| manager | 异步任务管理、用户工厂 |

## 八、模块依赖关系总览

```
ruoyi-admin（启动）
  ├── ruoyi-framework（核心）→ ruoyi-system、ruoyi-common
  ├── ruoyi-quartz → ruoyi-common
  ├── ruoyi-generator → ruoyi-common
  └── ai-devops → ruoyi-common
```
